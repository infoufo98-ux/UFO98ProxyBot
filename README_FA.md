# ربات UFO98 Proxy — نسخه اولیه

این پروژه یک نمونه اولیه برای ربات تلگرام است. امکانات فعلی:
- پاسخ به `/start`
- دکمه دریافت پروکسی و معرفی کانال‌ها
- افزودن/حذف لینک پروکسی توسط مدیر
- افزودن/حذف کانال‌های تبلیغاتی توسط مدیر
- آمار پایه کاربران و کلیک‌ها

## محدودیت‌های مهم
- این ربات خودش سرور پروکسی نمی‌سازد و لینک‌های پروکسی را میزبانی نمی‌کند.
- سلامت، امنیت یا ظرفیت لینک‌های ثبت‌شده به‌صورت خودکار بررسی نمی‌شود.
- داده‌ها در فایل محلی `data.json` ذخیره می‌شوند؛ در سرویس‌هایی با فایل‌سیستم موقت، داده‌ها ممکن است از بین بروند.
- این نسخه برای آزمایش اولیه است، نه بهره‌برداری تضمین‌شده برای ۵۰۰۰ کاربر هم‌زمان.
- لینک‌های پروکسی را فقط از منابع قابل اعتماد وارد کنید. توکن ربات را محرمانه نگه دارید.

## اجرا روی کامپیوتر شخصی (پس از نصب Python 3.11 یا جدیدتر)
1. پوشه را استخراج کنید.
2. PowerShell را در همان پوشه باز کنید.
3. محیط مجازی بسازید:
   `py -m venv .venv`
4. محیط مجازی را فعال کنید:
   `.\.venv\Scripts\Activate.ps1`
   اگر ویندوز اجرای اسکریپت را مسدود کرد، می‌توانید به‌جای فعال‌سازی از مسیر مستقیم پایتون محیط مجازی استفاده کنید.
5. وابستگی‌ها را نصب کنید:
   `python -m pip install -r requirements.txt`
6. فایل `.env.example` را به `.env` کپی کنید و مقادیر را پر کنید.
7. در این نسخه برنامه `.env` را خودکار نمی‌خواند؛ متغیرها را در همان PowerShell تنظیم کنید:
   `$env:BOT_TOKEN="توکن-ربات"`
   `$env:ADMIN_IDS="شناسه-عددی-مدیر"`
8. اجرا:
   `python bot.py`

## راه‌اندازی اولیه و شناسه مدیر
- ابتدا فقط `BOT_TOKEN` را تنظیم کنید و برنامه را اجرا کنید.
- به ربات خود پیام `/myid` بدهید و شناسه عددی را یادداشت کنید.
- برنامه را متوقف کنید، سپس `ADMIN_IDS` را با آن شناسه تنظیم و دوباره اجرا کنید.
- توکن را در چت عمومی یا فایل‌های قابل انتشار قرار ندهید. اگر توکن افشا شد، در BotFather آن را باطل و جایگزین کنید.

## دستورهای ربات
- `/start`
- `/help`
- `/channels`
- `/getproxy`
- `/myid`
- `/admin` (مدیر)
- `/addproxy https://t.me/proxy?...` (مدیر)
- `/delproxy` (مدیر؛ حذف همه پروکسی‌ها)
- `/addchannel نام کانال | https://t.me/channel` (مدیر)
- `/delchannels` (مدیر؛ حذف همه کانال‌ها)
- `/stats` (مدیر)

## توسعه بعدی
برای استفاده عمومی باید میزبانی دائمی، ذخیره‌سازی پایدار، پایش واقعی اتصال، کنترل سوءاستفاده، محدودسازی نرخ درخواست‌ها، ثبت رخدادها و آزمون بار اضافه شود. هزینه و ظرفیت سرور به تعداد کاربران هم‌زمان و ترافیک بستگی دارد.
